대시보드 자동 연동 가이드

이 파일을 Claude Code에 붙여넣고 "실행해줘"라고 하면 됩니다.

사용자에게 질문하지 마세요. 모든 정보는 프로젝트 파일에 있습니다.
못 찾은 항목은 기본값(0, 빈 배열)을 넣으세요. 데이터를 임의로 만들지 마세요.

구축 프로세스 (모든 태스크 공통)

Phase 1
시드 구축
→
Phase 2
시드 검증
→
Phase 3
대화 생성
→
Phase 4
품질 검증

단계 이름은 반드시 위 4개를 사용하세요. detail만 태스크별로 다르게 작성합니다.

실행 순서

1단계

프로젝트 전체 탐색 질문 금지

Explore 에이전트로 프로젝트를 매우 철저하게 탐색하세요.

탐색 대상찾는 정보
README.md, CLAUDE.md, docs/*.md태스크 ID, 이름, 목적, Tier, 목표/최소 수량
*.yaml, *.json, config/언어 비율, CoT 비율, 설정값
data/, seed/, prompt/시드 데이터 종류, 수량, 프롬프트 파일
result/, output/, log/결과 파일 (.jsonl, .json), 로그
scripts/, script/, src/파이프라인 코드, 메인 스크립트

못 찾으면 폴더명에서 추론하거나 기본값을 넣으세요.

2단계

결과 파일 직접 파싱

결과 파일을 Python으로 직접 읽어서 통계를 집계하세요.

집계 항목찾는 필드summary 필드
완료 건수결과 파일 라인 수dataStats.completed
통과율format_ok, passed, validdataStats.pass_rate
평균 턴 수messages 배열 길이dataStats.avg_turns
언어 분포language, langdataStats.lang
CoT 분포cot_mode, cotdataStats.cot
카테고리 분포domain, category, typedataStats.domains
횡단차원cross_cutting, dimensioncrossDims
횡단차원별 턴 분포횡단차원별 턴 수 집계crossDims[].turnDist

이 태스크만의 고유 지표를 적극적으로 찾아 넣으세요.

3단계

구축 예시(samples) 추출

결과 파일에서 횡단차원별 1건씩 대표 샘플을 추출하세요.

필수: messages에 role: "system" 메시지를 첫 번째로 포함
결과 파일에 없으면 프로젝트에서 시스템 프롬프트를 찾아서 삽입
금지 시스템 프롬프트를 임의로 생성하지 마세요. 못 찾으면 없이 보내세요.
4단계

sync 코드를 파이프라인 끝에 삽입

메인 스크립트의 맨 마지막에 삽입. 1~3단계에서 파악한 실제 변수명에 맞게 조정하세요.

# ============================================================
# 대시보드 자동 동기화 (수정 불필요)
# ============================================================
try:
    _summary = {
        "id": "...",          # 1단계에서 찾은 값
        "name": "...",
        "desc": "...",
        "status": "wip",
        "info": { ... },
        "seeds": [ ... ],
        "crossDims": [ ... ],
        "dataStats": { ... },
        "pipeline": [
            {"phase": "Phase 1", "name": "시드 구축",  "detail": "...", "status": "..."},
            {"phase": "Phase 2", "name": "시드 검증",  "detail": "...", "status": "..."},
            {"phase": "Phase 3", "name": "대화 생성",  "detail": "...", "status": "..."},
            {"phase": "Phase 4", "name": "품질 검증",  "detail": "...", "status": "..."},
        ],
        "issues": [ ... ],
        "samples": [ ... ],
    }

    import json as _json
    from pathlib import Path as _Path
    _out = _Path("result/summary.json")
    _out.parent.mkdir(parents=True, exist_ok=True)
    _out.write_text(_json.dumps(_summary, ensure_ascii=False, indent=2), "utf-8")

    import urllib.request as _ur
    _WEBHOOK = "https://script.google.com/macros/s/AKfycbxBOGVEO2CzCbVaF8e0QkN-3BiXItnhj2AQLuzK2BM3q2k5VAK7FFqipVA0KWCQLAuE/exec"
    _req = _ur.Request(_WEBHOOK, data=_json.dumps(_summary, ensure_ascii=False).encode("utf-8"),
                       headers={"Content-Type": "application/json"})
    _ur.urlopen(_req, timeout=60)
    print("[dashboard] 동기화 완료")
except Exception as _e:
    print(f"[dashboard] 동기화 실패 (무시): {_e}")
5단계

테스트 전송

4단계에서 삽입한 코드를 파이프라인 실행 없이 바로 테스트하세요.

  1. 2~3단계에서 파싱한 데이터로 _summary 구성
  2. Bash 도구로 Python 실행하여 webhook 전송
  3. 전송 결과 출력

반드시 5단계까지 완료하세요. 코드 삽입만 하고 끝내지 마세요.
